### 1. Щит управления насосом с VFD (преобразователь частоты)

**Задача:**  
Сборка и настройка щита управления для насосного оборудования.

**Структура схемы:**

| Цепь | Компоненты |
|------|------------|
| **Цепь управления** | Автомат → Реле контроля фаз → Реле уровня жидкости → Кнопки → Катушка контактора |
| **Силовая цепь** | Фильтр → Контактор → VFD → Насос |

**Что делал:**  
- Собрал щит по схеме.  
- Настроил VFD для плавного пуска насоса.  
- Проверил работу защиты (реле уровня жидкости, контроль фаз).  
- Научился читать электрические схемы и подключать VFD.

## 📐 Мои схемы в CADe SIMU

### Схема 1. Классический пуск двигателя (без ПЛК)

| Компоненты | Обозначение |
|------------|-------------|
| Автомат | QF |
| Контактор | KM |
| Тепловое реле | FR |
| Кнопка "Пуск" | SB1 (NO) |
| Кнопка "Стоп" | SB2 (NC) |
| Двигатель | M |

**Как работает:**  
- Самоподхват через NO контакт контактора.  
- Защита от перегрузки через тепловое реле.  
- Остановка через кнопку "Стоп".

### Схема 2. Управление двигателем через ПЛК (Siemens)

| Входы ПЛК | Выходы ПЛК | Оборудование |
|-----------|------------|--------------|
| Кнопка "Пуск" | Выход на контактор | Контактор |
| Кнопка "Стоп" | Выход на лампу "Работа" | Лампа "Работа" |
| Датчик (опционально) | Выход на лампу "Ошибка" | Лампа "Ошибка" |

**Логика:**  
- ПЛК получает сигнал с кнопок.  
- По программе включает/выключает контактор.  
- Контролирует состояние двигателя и выводит сигналы на лампы.
